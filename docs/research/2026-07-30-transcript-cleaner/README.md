# «Русификатор»: утилита очистки голосовых расшифровок

## Текущий вывод

«Русификатор» стоит делать нативным приложением для macOS на `SwiftUI` с
точечным использованием `AppKit`. Главное окно открывается из строки меню через
`MenuBarExtra` со стилем `.window`, настройки живут в отдельной сцене
`Settings`. API-ключ хранится в macOS Keychain, остальные параметры — в
`UserDefaults`.

Для первого релиза нужен один короткий путь: вставить расшифровку, запустить
очистку, скопировать готовый текст. История не сохраняется. Запросы уходят через
`URLSession` в OpenAI-совместимый `/v1/chat/completions`; системный промпт из
брифа передаётся без изменений.

- название приложения: **«Русификатор»**;
- рекомендуемый путь:
  `rusifikator-macos/`;
- рекомендуемый идентификатор пакета: `dev.gotacat.Rusifikator`.

Название выбрано пользователем. Несмотря на него, модель сохраняет язык входного
текста и не ограничивается русским.

## Что нужно проверить перед разработкой

1. Версии macOS на обоих Mac. Рекомендуемый минимум — macOS 14; если один
   компьютер старше, придётся пересмотреть минимум или использовать
   `NSStatusItem` и `NSPopover`.
2. Точный URL личного LiteLLM, наличие `/v1` в пути, формат ключа и имя модели.
3. Доступен ли провайдер по HTTPS. Для локального HTTP потребуется узкое
   исключение App Transport Security; глобально отключать ATS не следует.
4. Есть ли активная подписка Apple Developer Program. Без неё второй Mac сможет
   открыть сборку вручную через «Открыть всё равно», но нормальная раздача
   требует Developer ID и нотариального заверения.
