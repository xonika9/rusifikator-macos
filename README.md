# Русификатор для macOS

Нативная утилита строки меню, которая превращает голосовую расшифровку в
аккуратный русский текст через OpenAI-совместимый API. Каждый запуск обработки
изолирован: в запрос входят только фиксированный системный промпт и текст,
который находится в поле прямо сейчас. Последние пять успешных обработок
хранятся локально на Mac, но никогда не добавляются в следующие запросы.

По умолчанию приложение использует:

- адрес `https://liteapi.gotacat.dev/`;
- модель `proxy/gpt-5.6-terra`;
- маршрут `POST /v1/chat/completions`.

## Требования

- macOS 26;
- Xcode 26 со Swift 6.2 или новее.

## Сборка и тесты

```sh
swift build
swift test
scripts/test-system-prompt.sh
```

## Упаковка и установка

```sh
scripts/package-app.sh
scripts/smoke-test-app.sh dist/Rusifikator.app
cp -R dist/Rusifikator.app /Applications/
open /Applications/Rusifikator.app
```

После запуска значок появится в строке меню; в Dock приложение не показывается.
Левый клик по значку открывает редактор, правый — меню с версией, настройками и
выходом. В настройках нужно ввести API-ключ и нажать «Сохранить». Ключ нельзя
передавать в чат, добавлять в исходный код или вводить в команды терминала.

Скрипт создаёт `dist/Rusifikator.app`, проверяет пакет и ставит локальную
ad-hoc подпись. Такая подпись подходит для локальной разработки, но не заменяет
Developer ID и нотарификацию. Запуск на другом Mac и прохождение Gatekeeper там
пока не проверены.

## Настройка и приватность

- Адрес и модель хранятся в `UserDefaults`.
- API-ключ хранится только в macOS Keychain и привязывается к защищённому
  HTTPS-origin. При смене провайдера ключ нужно ввести заново.
- Последние пять пар «исходник — результат» записываются в локальный JSON-файл
  внутри `Application Support`. Историю можно целиком удалить из приложения;
  в аналитику, журналы и новые запросы она не передаётся.
- Очистка поля отменяет текущий запрос и удаляет исходник, результат и ошибку,
  но не затрагивает историю.
- Копирование выполняется только по явному нажатию. После этого текст находится
  в системном буфере обмена и может быть доступен его менеджерам, Universal
  Clipboard и другим приложениям.
- Сам провайдер получает текущую расшифровку. Его хранение и обработка данных
  находятся вне контроля приложения и должны оцениваться отдельно.

Проверка соединения использует черновые значения из окна настроек и короткий
служебный текст. Она не сохраняет настройки автоматически.

Автозапуск через `SMAppService` доступен для копии, установленной в
`/Applications`. После включения macOS может потребовать подтверждение в
системных настройках.

## Разработка в Xcode

Открой `Package.swift` через `File → Open` в Xcode. Для обычной разработки
достаточно `swift build` и `swift test`; готовый пакет создаётся отдельным
скриптом, потому что проект намеренно остаётся компактным Swift Package.

## Значки

В строке меню временно используется системный SF Symbol
`character.cursor.ibeam`; у пакета приложения пока стандартный значок macOS.
Это временные заменяемые элементы.

Для финальной версии понадобятся два разных исходника:

- значок приложения — квадратный PNG 1024×1024 без предварительно скруглённых
  углов; из него создаётся `.icns` или набор AppIcon;
- значок строки меню — монохромный шаблон с прозрачным фоном, желательно
  векторный PDF или SVG, рассчитанный на размер около 18×18 pt.

## Что ещё требует проверки владельцем

- успешный живой запрос с настоящим API-ключом и выбранной моделью;
- качество результата на нескольких реальных расшифровках;
- запуск при входе после перезагрузки установленной копии;
- перенос и запуск пакета на втором Mac;
- правила хранения расшифровок на стороне API-провайдера.
