# Русификатор для macOS

Минимальный каркас нативной утилиты строки меню для macOS 26. Сейчас в нём есть
постоянный `MenuBarExtra` со стилем окна, системный значок, окно настроек и
фиксированный системный промпт. Сеть, API-ключ и рабочий редактор в этот этап не
входят.

## Требования

- macOS 26;
- Xcode 26 с Swift 6.

## Сборка и тесты

```sh
swift build
swift test
scripts/test-system-prompt.sh
```

## Упаковка и установка

```sh
scripts/package-app.sh
scripts/smoke-test-app.sh dist/Rusifikator.app
cp -R dist/Rusifikator.app /Applications/
open /Applications/Rusifikator.app
```

Скрипт создаёт `dist/Rusifikator.app`, проверяет `Info.plist` и ставит локальную
ad-hoc подпись. Такая подпись не заменяет Developer ID и notarization:
распространение на другой Mac и прохождение Gatekeeper там не проверены.

## Настройка и приватность

Поля провайдера и хранение API-ключа появятся на следующем этапе. Текущий каркас
не выполняет сетевых запросов и не сохраняет пользовательские тексты.
`SystemPrompt.txt` поставляется как неизменяемый ресурс приложения.

## Значки

В строке меню временно используется системный SF Symbol
`character.cursor.ibeam`. Перед выпуском нужно заменить его на шаблонный значок
строки меню, а также добавить отдельный значок приложения в `Assets.car`.
